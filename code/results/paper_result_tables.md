## 表 E v3 负结果（规则迭代过拟合证据）

| 数据 | v2 | v3 |
|---|---|---|
| dev 180 | 64.4% / κ0.453 / macro 0.462 | 66.7% / κ0.512 / macro 0.576 |
| test 179 | **63.1% / κ0.373 / macro 0.358** | 59.8% / κ0.339 / macro 0.329 |

- 原因：dev 稀有类过少（C=6、N=11），v3 在 dev 上的规则在 test 全变假阳（净 -6 条）。
- 结论：主规则基线用 v2；v3 作为"稀有类少时规则迭代会过拟合"的负结果/限制。

## 表 F 规模与成本（引用旧结果时注意口径）
